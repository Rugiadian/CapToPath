# CapToPath (픽픽 연동형 스크린샷 경로 클립보드 복사 CLI)

> 캡처 도구 **'픽픽(PicPick)'**으로 화면을 캡처한 직후, 생성된 이미지의 **절대 파일 경로**를 Windows 클립보드에 즉시 복사해 주는 초경량 CLI 백그라운드 유틸리티입니다.  
> 노션, 디스코드, 블로그 에디터, 개발 툴, 터미널 등에서 `Ctrl + V`로 이미지 파일 경로를 즉시 붙여넣을 수 있습니다.

---

## ✨ 주요 특징

1. **완전 백그라운드 무음 실행 (No Console Window)**
   - 콘솔 창(검은색 CMD 창) 깜빡임이 **0.0초**도 발생하지 않는 Windows GUI 서브시스템 바이너리로 빌드되었습니다.
2. **비간섭형(Non-Activating) 모던 토스트 알림**
   - 클립보드 복사가 완료되면 윈도우 우측 하단에 세련된 플로팅 알림창이 약 **1.2~1.3초간** 표시된 후 자동 종료됩니다.
   - 알림창이 뜨더라도 **현재 작업 중이던 창의 포커스를 절대 뺏지 않으므로**, 캡처 직후 즉시 `Ctrl + V`를 입력해도 작업 흐름이 끊기지 않습니다.
3. **완벽한 공백 및 따옴표 경로 처리**
   - 경로에 띄어쓰기(예: `C:\My Screenshots\2026 09 21.png`)나 따옴표가 포함되어 있어도 잘림 없이 온전한 Full Path로 복사됩니다.
   - 파일 저장 직후 디스크 I/O 딜레이까지 고려한 자동 재시도 및 정규화 알고리즘이 적용되어 있습니다.
4. **픽픽 자동 감지 엔진 (Smart Auto-Detection)**
   - 픽픽 버전 특성상 매개변수 `"%1"`이 실제 파일명으로 치환되지 않거나 인자가 누락되는 경우에도, 픽픽 설정(`picpick.ini`)의 스크린샷 자동 저장 폴더를 스스로 조회하여 **방금 캡처된 실제 최신 이미지 파일**을 100% 자동 추적 및 복사합니다.
5. **단일 실행 파일 (.exe) 배포**
   - 추가 DLL이나 설치 프로그램 없이 `CapToPath.exe` 단 하나로 독립 실행됩니다.
   - 다른 PC로 이동해도 바로 작동하는 Self-Contained 배포본 제공.

## 🚀 빠른 시작 및 픽픽(PicPick) 연동 방법

### 1단계: 프로그램 위치 확인
* `G:\Git\CapToPath\CapToPath.exe` (또는 원하는 폴더로 복사)

### 2단계: 픽픽(PicPick) 외부 프로그램 등록
1. **픽픽 실행** 후 상단 메뉴에서 **[파일] → [프로그램 설정]** (또는 단축키 `Ctrl + K`)을 클릭합니다.
2. 좌측 메뉴에서 **[외부 프로그램]** (또는 프로그램 연결) 탭을 선택합니다.
3. **[추가]** 버튼을 클릭하고 다음과 같이 입력합니다:
   * **이름**: `CapToPath`
   * **경로**: `G:\Git\CapToPath\CapToPath.exe` (실제 exe 파일이 위치한 절대 경로)
   * **매개변수**: `"%1"`  *(반드시 큰따옴표로 감싸서 입력 권장)*
4. **[확인]**을 눌러 등록을 완료합니다.

### 3단계: 캡처 후 자동 실행 설정
1. 픽픽 설정 창 좌측 메뉴에서 **[캡처]** 탭으로 이동합니다.
2. **[캡처 후 결과 작업]** 드롭다운 항목을 찾습니다.
3. 옵션 목록 중 **`외부 프로그램으로 보내기 -> CapToPath`**를 선택합니다.
4. (선택 사항) **[자동 저장]** 탭에서 스크린샷이 저장될 로컬 폴더(예: `C:\Screenshots`) 및 파일 이름 형식을 지정합니다.
5. 설정 창에서 **[확인]**을 클릭하여 설정을 저장합니다.

### 4단계: 사용하기
* 픽픽 단축키(예: `PrintScreen`, `Shift + PrintScreen` 등)로 화면을 캡처합니다.
* 캡처 직후 우측 하단에 *"스크린샷 경로가 복사되었습니다."* 알림이 스르륵 나타났다 사라집니다.
* 원하는 곳(노션, 디스코드, IDE 등)에서 **`Ctrl + V`**를 누르면 파일 경로가 바로 입력됩니다!

## 🛠️ CLI 사용법 및 옵션

터미널이나 배치 파일, 타 캡처 도구에서도 직접 호출할 수 있습니다.

```cmd
CapToPath.exe "<이미지_파일_절대경로>" [옵션]
```

### 지원 옵션
| 옵션 | 설명 |
| :--- | :--- |
| `"<경로>"` | 복사할 이미지 파일의 절대 또는 상대 경로 (공백 포함 가능) |
| `--silent`, `-s` | 토스트 알림 창을 띄우지 않고 0.01초 만에 클립보드 복사 후 조용히 종료 |
| `--help`, `-h`, `/?` | 사용법 및 픽픽 연동 가이드 다이얼로그 표시 |

#### 실행 예시
```cmd
REM 일반 실행 (토스트 알림 1.3초 노출 후 자동 종료)
CapToPath.exe "C:\My Screenshots\2026-09-21 03.18.00.png"

REM 완전 무음 모드 (0.01초 즉시 복사 및 종료)
CapToPath.exe --silent "C:\My Screenshots\2026-09-21 03.18.00.png"
```

## 📂 프로젝트 구조

```
G:\Git\CapToPath\
├── CapToPath.exe           # 최종 단일 실행 파일 (루트 배포본)
├── README.md               # 사용자 설명서 및 픽픽 연동 가이드
├── build.bat               # 원클릭 릴리스 빌드 스크립트
├── dist\
│   └── CapToPath.exe       # 무설치 독립 배포용 (.NET 미설치 PC에서도 작동, ~51MB)
├── dist_light\
│   └── CapToPath.exe       # 런타임 보유 PC용 초경량 단일 파일 (~180KB)
└── src\
    ├── CapToPath.csproj    # .NET 프로젝트 설정
    ├── Program.cs          # 인자 파싱, 클립보드 복사, 예외/재시도 처리 메인 루틴
    ├── ToastForm.cs        # 비활성화(Non-Activating) 모던 토스트 팝업 폼
    └── app.ico             # 애플리케이션 임베디드 아이콘
```

## 🔧 소스 코드 빌드 방법

Windows 환경에 .NET SDK 8.0 이상(권장: .NET 10)이 설치되어 있다면 루트의 `build.bat`을 더블클릭하거나 아래 명령어로 즉시 빌드할 수 있습니다:

```cmd
REM 독립 실행형 단일 exe 빌드
dotnet publish -c Release -o dist

REM 초경량 단일 exe 빌드 (.NET 런타임 공유)
dotnet publish -c Release -p:SelfContained=false -p:EnableCompressionInSingleFile=false -o dist_light
```
